# Excel差分比較ツール（追加機能版）

Python **標準ライブラリのみ**で実装した Excel 差分比較ツールです。
外部パッケージ（openpyxl 等）は使用していません。

* `.xlsx` / `.xlsm` は `zipfile` + `xml.etree` で自作パーサにより読み込みます
  （`.xlsm` はマクロ付き形式ですが中身の構造は `.xlsx` と同じ。シート値のみ比較し、マクロは対象外）
* GUI は `tkinter`（Canvas）
* 行整列は `difflib.SequenceMatcher`
* 正規化は `unicodedata`（NFKC で全角・半角同一視）

## 実行方法

```powershell
# サンプルを生成
py make_samples.py

# サンプルで起動（2ファイル / 3ファイル）
py run.py --sample
py run.py --sample3

# 任意の2ファイルで起動（.xlsx / .xlsm / .csv / .tsv）
py run.py a.xlsx b.xlsx

# 3ファイル比較（1つ目が基準）
py run.py a.xlsx b.xlsx c.xlsx

# 空で起動し、[ファイル]メニューから開く
py run.py
```

Python は Windows の場合 `py`、他環境では `python3` を使ってください。

## 画面と操作

```
[◀前差分][次差分▶] | [⇄行列入替][1列表示][◀列][列▶][同一値強調] | [行対応編集][対応付け][対応解除][自動復元] | [Undo][Redo] | [＋Cファイル]
┌────────┬───────────┬────┬───────────┬────┬───────────┐
│差分一覧 │ A（基準）  │対応│ B         │対応│ C（任意）  │
└────────┴───────────┴────┴───────────┴────┴───────────┘
元セル：A C5 | 同一値：A2件 B3件 | 手動対応：… | 集計（3ファイル比較）：追加/削除/変更…
```

* **セル選択**：クリック。ステータスバーに元セルアドレスを表示
* **行列入替**：全パネル同時に転置。選択セル・同一値ハイライトは維持
* **1列表示**：1列だけを幅広で表示し、長い文字列を折り返して比較（下記）
* **同一値強調**：ONにしてセルを選択すると、同じ値のセルを全パネルで青枠表示
* **行対応編集**：モードにして各パネルを1行ずつクリック →［対応付け］。右クリックメニューも可
* **セルの大きさ変更**：列・行ごとに個別サイズを設定（下記）

### 3ファイル比較

パネルは **A（基準）／B／C** の最大3つです。Cを開くと3ファイル比較、閉じると
従来どおりの2ファイル比較に戻ります。

* ［ファイル］メニュー、またはツールバーの［＋Cファイル］でCを開く／閉じる
* 起動時に3つ指定：`py run.py a.xlsx b.xlsx c.xlsx`
* **行の整列は常に A が基準**。「A↔B」「A↔C」を個別に整列し、Aの行位置で1本に統合します
  * BとCの両方に同じ内容で増えた行は、同じ行スロットにまとめて表示します
* **セルの色**：その行に存在するパネルの値が1つでも食い違えば「変更（橙）」。
  行が無いパネルはグレーになります（例：A・Cにあり、Bで削除された行は
  A/Cが赤・Bがグレー）
* 集計の意味：**追加**＝Aに無い行、**削除**＝Aにあり他のどれかに無い行、
  **変更**＝全パネルに行はあるが値が違う

### 列幅・行高の個別変更

セル（列・行）ごとに異なる大きさを設定できます。

* **ヘッダ境界をドラッグ**：列見出しの右端をドラッグ→**列幅**、行見出しの下端をドラッグ→**行高**
* **境界をダブルクリック**：列は内容に合わせて**自動フィット**、行は既定へ戻す
* ツールバーの **幅／高** スピンボックスは全セル共通の**既定値**（個別設定していない列・行に適用）
* ［表示］→「セルの大きさを既定に戻す」で個別設定をすべてクリア
* **行高は全パネル共通**（対応行が必ず同じ高さで並び、比較しやすい）。**列幅はパネルごとに独立**
* 行列入替中は、スロット（元の行）の大きさが横幅として反映されます

### 1列表示モード

1列だけを幅広（既定380px）で表示し、セルの内容を**折り返して**各パネルで比較します。
1つのセルに長い名前などが入っている場合に全文を確認しやすくなります。

* ［1列表示］で切替。表示する列は選択セルから自動で決まります
* ［◀列］［列▶］で表示する列を送れます（ステータスバーに「3/5（価格）」等を表示）
* 各パネルは**同じ行高**で揃うため、対応するセルを直接見比べられます
* **行列入替と併用**すると、1レコードを縦にフィールド単位で比較できます
  （例：転置＋1列表示で「A3行目 vs B3行目 vs C3行目」を 商品ID／商品名／価格… と縦に並べて比較）

```
通常の1列表示（フィールド「商品名」を縦に比較）    転置＋1列表示（1レコードを縦に比較）
┌──┬──────────────┐  ┌────┬──────────────┐  ┌──────┬──────────────┐
│行│ 商品名        │  │行  │ 商品名        │  │A3 / B3 / C3 行       │
├──┼──────────────┤  ├────┼──────────────┤  ├──────┼──────────────┤
│2 │ 商品A         │  │2   │ 商品A         │  │商品ID│ A002 / A002   │
│5 │ 商品E         │  │5   │ 商品E改(変更) │  │商品名│ 商品B / 商品B │
└──┴──────────────┘  └────┴──────────────┘  │価格  │ 1200 / 1300(変更)
                                              └──────┴──────────────┘
```

### 設計メモ

* **行整列**：`difflib` の opcodes を RowSlot（各パネルの行番号/種別）の列に変換。
  `equal`→一致、`replace`→位置対応で変更、`delete`/`insert`→片側のみ。
* **3ファイルの整列**：基準A に対して「A↔B」「A↔C」を個別に整列し、
  A の行位置でマージして1本のスロット列にする（`diffengine._align_two`）。
  A に無い行（B/C だけの行）は、内容が同じものを同じスロットへまとめる。
* **手動対応**：1パネル1行を保つため「スワップ方式」。対応先の行を基準スロットへ
  移し、押し出された行を玉突きで組み替えて件数の整合を保つ。
* **Undo/Redo**：整列リスト全体を snapshot して push/pop。確実に元へ戻る。
* **同一値**：比較実行時に「正規化キー → セル位置一覧」のインデックスを作成
  （仕様 3.12）。選択時は辞書引きのみで高速。

   ├─ model.py            Cell / Sheet / Workbook, アドレス変換

   ├─ reader.py           .xlsx / .xlsm / .csv 読込

# Excel差分比較ツール（追加機能版）

Python **標準ライブラリのみ**で実装した Excel 差分比較ツールです。
外部パッケージ（openpyxl 等）は使用していません。

* `.xlsx` は `zipfile` + `xml.etree` で自作パーサにより読み込みます
* GUI は `tkinter`（Canvas）
* 行整列は `difflib.SequenceMatcher`
* 正規化は `unicodedata`（NFKC で全角・半角同一視）

## 実行方法

```powershell
# サンプルを生成
py make_samples.py

# サンプルで起動
py run.py --sample

# 任意の2ファイルで起動（.xlsx / .csv / .tsv）
py run.py left.xlsx right.xlsx

# 空で起動し、[ファイル]メニューから開く
py run.py
```

Python は Windows の場合 `py`、他環境では `python3` を使ってください。

## 画面と操作

```
[◀前差分][次差分▶] | [⇄行列入替][1列表示][◀列][列▶][同一値強調] | [行対応編集][対応付け][対応解除][自動復元] | [Undo][Redo]
┌────────┬───────────┬────┬───────────┐
│差分一覧 │ 左Excel   │対応│ 右Excel   │
└────────┴───────────┴────┴───────────┘
元セル：C5 | 同一値：左2件 右3件 | 手動対応：… | 集計：追加/削除/変更…
```

* **セル選択**：クリック。ステータスバーに元セルアドレスを表示
* **行列入替**：左右同時に転置。選択セル・同一値ハイライトは維持
* **1列表示**：1列だけを幅広で表示し、長い文字列を折り返して左右比較（下記）
* **同一値強調**：ONにしてセルを選択すると、同じ値のセルを左右で青枠表示
* **行対応編集**：モードにして左右を1行ずつクリック →［対応付け］。右クリックメニューも可

### 1列表示モード

1列だけを幅広（既定380px）で表示し、セルの内容を**折り返して**左右で比較します。
1つのセルに長い名前などが入っている場合に全文を確認しやすくなります。

* ［1列表示］で切替。表示する列は選択セルから自動で決まります
* ［◀列］［列▶］で表示する列を送れます（ステータスバーに「3/5（価格）」等を表示）
* 左右は**同じ行高**で揃うため、対応するセルを直接見比べられます
* **行列入替と併用**すると、1レコードを縦にフィールド単位で比較できます
  （例：転置＋1列表示で「左3行目 vs 右3行目」を 商品ID／商品名／価格… と縦に並べて比較）

```

┌──┬──────────────┐  ┌────┬──────────────┐  ┌──────┬──────────────┐
│行│ 商品名        │  │行  │ 商品名        │  │左3/右3行            │
├──┼──────────────┤  ├────┼──────────────┤  ├──────┼──────────────┤
│2 │ 商品A         │  │2   │ 商品A         │  │商品ID│ A002 / A002   │

                                              └──────┴──────────────┘
```

### 設計メモ

* **行整列**：`difflib` の opcodes を RowPair（左行/右行/種別）の列に変換。
  `equal`→一致、`replace`→位置対応で変更、`delete`/`insert`→片側のみ。
* **手動対応**：1:1 を保つため「スワップ方式」。左L↔右Rを確定する際、
  L の旧相手と R の旧相手を玉突きで組み替え、件数の整合を保つ。
* **Undo/Redo**：整列リスト全体を snapshot して push/pop。確実に元へ戻る。
* **同一値**：比較実行時に「正規化キー → セル位置一覧」のインデックスを作成
  （仕様 3.12）。選択時は辞書引きのみで高速。
